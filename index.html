    About this site

    Built like a scrapbook, maintained like a parts bin.

    The visual language is inspired by handmade craft, stitched fabric, cardboard, buttons, and playful invention. It intentionally avoids using any direct videogame assets, logos, or copyrighted art.

    Easy update flow

    1. Put your CAD model in assets/models/.
    2. Add one object to projects in app.js.
    3. Push to GitHub Pages.

    Made with fabric scraps, copper traces, and static hosting.
